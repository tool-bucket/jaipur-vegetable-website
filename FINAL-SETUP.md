# FreshJaipur Final E-commerce

Included:
- Product add to cart
- 250g / 500g / 1kg quantity options
- ₹200 minimum order
- Cart + checkout
- Customer delivery details
- Current-location / Google Maps link
- Order confirmation
- Node.js + Express backend
- MongoDB order database
- Admin login
- Admin order dashboard
- Order status management
- WhatsApp optional

Only external setup remains: create/connect MongoDB Atlas and deploy the backend. Those steps require credentials owned by the site owner.
